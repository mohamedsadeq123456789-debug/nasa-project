# NASA Website Clone

A front-end recreation of the NASA homepage: hero section, mission highlights, featured news and multimedia sections.

**Stack:** HTML · CSS

🔗 **Live demo:** https://mohammad-bataineh.github.io/nasa-project/

## Features

- Header with dropdown navigation (News & Events, Multimedia, NASA+)
- Full-width hero with call-to-action
- Mission / Space Station cards
- Featured news grid with images
- Pure HTML and CSS, no frameworks

## Run locally

Open `index.html` in any browser.

> Educational project. Not affiliated with NASA.
